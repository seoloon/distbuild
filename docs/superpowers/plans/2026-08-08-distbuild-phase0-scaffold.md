# DistBuild Phase 0 — Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the DistBuild monorepo skeleton — Cargo workspace with five placeholder library crates plus a worker-core binary crate, a Tauri v2 + SolidJS(TS) desktop app scaffold wired to a `ui/` frontend directory and Tailwind v4, and a `justfile` for `dev`/`build`/`fmt`/`test` — so Phase 1 has a compiling, testable base to build the protocol and discovery crates into.

**Architecture:** A single Cargo workspace at the repo root owns every Rust crate, including the Tauri app's `src-tauri`. `crates/*` are empty library crates for now (real logic starts Phase 1). `apps/worker-core` is a placeholder binary. `apps/desktop` is generated by `create-tauri-app` (SolidJS + TS template) then adjusted: its frontend directory is renamed from the template default `src/` to `ui/` per spec, and Tailwind v4 is wired in via `@tailwindcss/vite`. The desktop UI ships a minimal two-tab (Master/Worker) shell with no business logic.

**Tech Stack:** Rust 1.95 / Cargo workspace (resolver "2"), Tauri v2, SolidJS + Vite 6 + TypeScript, Tailwind CSS v4, pnpm, `just`.

## Global Constraints

- Workspace crates: `crates/discovery`, `crates/protocol`, `crates/executor`, `crates/artifacts`, `crates/diagnostics`, `apps/worker-core`, `apps/desktop/src-tauri` — exact paths per spec's monorepo layout.
- Frontend lives at `apps/desktop/ui/`, not the create-tauri-app default `apps/desktop/src/`.
- No `.unwrap()` outside tests, no `panic!` in library code (rule 7) — trivially satisfied in Phase 0 since crates are empty, but must hold for any code written in this plan (e.g. `worker-core`'s `main.rs`).
- `cargo fmt`, `cargo clippy -- -D warnings` must be clean before each commit (rule 8).
- Conventional Commits (`feat:`, `chore:`, etc.) for every commit (rule 9).
- This phase does **not** add any of the real dependencies (`mdns-sd`, `git2`, `axum`, `tokio-tungstenite`, `rustls`, `rcgen`, `zip`) — those land with the crate's real implementation in Phase 1+. Only shared, cross-cutting deps (`tokio`, `serde`, `serde_json`, `tracing`, `tracing-subscriber`, `thiserror`, `anyhow`) are pre-declared at the workspace level so later phases don't need to re-pin versions.
- Stop after this plan is fully executed and committed. Do not begin Phase 1 (protocol/discovery implementation) — the spec requires an explicit "go" from the user first.

- [ ] **Step 2: Wire the plugin into Vite**

`apps/desktop/vite.config.ts` — add the import and plugin entry:

```ts
import { defineConfig } from "vite";
import solid from "vite-plugin-solid";
import tailwindcss from "@tailwindcss/vite";

// @ts-expect-error process is a nodejs global
const host = process.env.TAURI_DEV_HOST;

// https://vite.dev/config/
export default defineConfig(async () => ({
  plugins: [solid(), tailwindcss()],

  // Vite options tailored for Tauri development and only applied in `tauri dev` or `tauri build`
  //
  // 1. prevent Vite from obscuring rust errors
  clearScreen: false,
  // 2. tauri expects a fixed port, fail if that port is not available
  server: {
    port: 1420,
    strictPort: true,
    host: host || false,
    hmr: host
      ? {
          protocol: "ws",
          host,
          port: 1421,
        }
      : undefined,
    watch: {
      // 3. tell Vite to ignore watching `src-tauri`
      ignored: ["**/src-tauri/**"],
    },
  },
}));
```

import { createSignal } from "solid-js";
import MasterTab from "./tabs/MasterTab";
import WorkerTab from "./tabs/WorkerTab";
import "./App.css";

type Tab = "master" | "worker";

function App() {
  const [tab, setTab] = createSignal<Tab>("master");

  return (
    <main class="flex h-screen w-screen flex-col bg-neutral-950 text-neutral-100">
      <nav class="flex border-b border-neutral-800">
        <button
          class={`px-4 py-2 text-sm ${tab() === "master" ? "border-b-2 border-neutral-100" : "text-neutral-500"}`}
          onClick={() => setTab("master")}
        >
          Master
        </button>
        <button
          class={`px-4 py-2 text-sm ${tab() === "worker" ? "border-b-2 border-neutral-100" : "text-neutral-500"}`}
          onClick={() => setTab("worker")}
        >
          Worker
        </button>
      </nav>
      <section class="flex-1 overflow-auto">
        {tab() === "master" ? <MasterTab /> : <WorkerTab />}
      </section>
    </main>
  );
}

export default App;
```

set shell := ["bash", "-uc"]

default:
    @just --list

# Run the desktop app in Tauri dev mode
dev:
    cd apps/desktop && pnpm tauri dev

    cargo build --workspace --release

# Format Rust and frontend code
fmt:
    cargo fmt --all
    cd apps/desktop && pnpm exec prettier --write ui

```
